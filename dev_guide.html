Technical Architecture and Systems Overview for Neutral Zone

Architecture Overview

Neutral Zone is a vanilla JavaScript web game rendering directly to an HTML5 Canvas using a 2D context. The architecture is driven by a main Game Loop and highly decoupled modular files.

State Management (state.js)

The entire game state is stored in simple, exportable JavaScript objects and arrays. This allows the simulation to act deterministically and to be injected flawlessly into testing frameworks.

export const state = { activeScout: null, selectedFighters: [], gameStarted: false, gameOver: false, lastTime: 0 };

Core Systems

Territory Hull Simulation

Territory is mapped dynamically using a Convex Hull algorithm (found in utils.js). The points of the hull are generated dynamically every frame based on the coordinates of the Home Planet and all living Scouts.

The total area formed by this hull calculates player domination percentages. Functions like pointInPolygon and doPolygonsIntersect guarantee units are repelled safely and miners stop harvesting if an asteroid exits the hull boundary.

Unit Steering and Collision

Unit movement in units.js relies on autonomous steering behaviors mapped with a slight physics layer. Units execute custom avoidance logic to prevent intersecting the Home Planet or Asteroids during travel.

A soft-body collision system repels overlapping entities using dynamic force vectors based on whether the unit is actively moving or idle (parking push logic).

The CPU AI (ai.js)

The CPU uses a deterministic state machine balancing economy, expansion, and offense within its logic ticks. By evaluating its current resource throughput and distance mapping against enemy scouts, the CPU makes localized decisions without cheating the game state.

Testing & Telemetry

Neutral Zone employs an offline headless testing framework utilizing Jest (test_runner.js). By bypassing the graphical renderer layer entirely, the game logic runs simulation iterations thousands of times faster than real-time to locate edge cases in unit navigation or combat balancing.

Simulation outputs are dumped directly to JSON JSON logs where properties like economy-to-military build ratios can be evaluated cleanly over epochs.
