Technical Architecture and Systems Overview for Neutral Zone

Architecture Overview

Neutral Zone is a vanilla JavaScript web game rendering directly to an HTML5 Canvas using a 2D context. The architecture is driven by a main Game Loop and highly decoupled modular files.

State Management (state.js)

The entire game state is stored in simple, exportable JavaScript objects and arrays scaled to a deterministic grid coordinate system (GRID_W = 20, GRID_H = 15). This allows the simulation to run decoupled from canvas pixels and execute in headless test environments.

export const state = { activeStation: null, activeStationPlayer: null, selectedFighters: [], selectionBox: null, currentPath: [], drawingPath: false, gameStarted: false, gameOver: false, lastTime: 0 };

Core Systems

Planar Graph & Territory Faces

Rather than a naive convex hull, territory is mapped using a planar graph face-tracing algorithm (in utils.js). getStationGraph links each station to up to 2 closest neighbors within MAX_CONNECTION_LENGTH = 5 grid units. getPlayerTerritoryHulls then traverses the directed angular adjacency cycles to extract closed polygon faces formed by 3 or more connected nodes.

The total area formed by these faces determines the 55% domination victory condition. Functions like isPointInTerritory and doTerritoriesIntersect enforce border physics, preventing overlaps and recalling miners when resources exit friendly territory.

Border Power & Perimeter Limits

Each player has a dynamic border power budget: maxPerimeter = (stations + 1) * 3.5. If the sum of connection edge lengths exceeds this capacity, the UI warns of overextension and restricts further remote station moves.

Unit Steering and Collision

Unit movement in units.js relies on autonomous steering behaviors mapped with a physics layer. Units execute avoidance logic to prevent intersecting the Home Planet or Asteroids during travel.

A soft-body collision system smoothly repels overlapping entities without deadlock, and units suffer a 50% movement speed penalty outside friendly territory.

The CPU AI (ai_expansioneer.js)

The CPU uses a deterministic state machine balancing economy, expansion, and offense within its logic ticks. By evaluating its current resource throughput and distance mapping against enemy scouts, the CPU makes localized decisions without cheating the game state.

Testing & Telemetry

Neutral Zone employs an offline headless testing framework (tests/ai_tuner.js and tests/test_runner.js). By bypassing the graphical renderer layer entirely, the simulation runs thousands of ticks per second to verify gameplay balance against six core tuning goals: no deadlock, balanced economy, threat defense, proactive offense, target match duration (~5 min), and exploit prevention.

For visual debugging, evaluate.html provides an in-browser scenario runner with speed controls ($1\times$ to $10\times$) and live execution telemetry.
